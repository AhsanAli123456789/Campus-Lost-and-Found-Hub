# Campus Lost & Found Hub (CLFH)

## Introduction

Campus Lost & Found Hub is a Java-based
application designed to help university students
report and recover lost belongings.

## Features

- Report lost items
- Report found items
- Search reported items
- Submit ownership claims
- Admin claim verification
- Track returned items
- Permanent data storage

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- File Handling
- Serialization

## OOP Concepts

1. Encapsulation
2. Inheritance
3. Polymorphism
4. Abstraction

## Project Structure

The project contains separate classes for
users, students, administrators, items,
claims, searching and file management.

## How to Run

Compile:

javac -d out src/*.java

Run:

java -cp out Main
